# Doce Sem Fogo

Crie um app mobile-first chamado "Receita Sem Fogo" (PT-BR), para pessoas que compraram um pacote de ebooks de confeitaria e vão usar o app como biblioteca de receitas + acesso aos ebooks originais. Implemente direto sem pausar pra aprovação de plano.

VISUAL: tema doce/confeitaria, paleta rosa clarinho + marrom chocolate + dourado (inspirado em brigadeiro/doce gourmet), tipografia arredondada e acolhedora, cards com fotos (pode gerar imagens de capa realistas de doces para cada receita/categoria, estilo fotografia de confeitaria profissional, sem texto sobreposto). Layout em coluna única max-w-[430px] centralizada, exatamente como os outros apps mobile que já fizemos (bottom nav fixo).

ESTRUTURA:
1. Tela Início: saudação, banner destaque com uma receita, atalhos para as categorias "Recheios" e "Brigadeiros", seção "Todas as receitas".
2. Tela Categorias: duas categorias grandes (Recheios e Brigadeiros) cada uma abrindo a lista de receitas daquela categoria.
3. Tela de lista de receitas por categoria, com busca por nome.
4. Tela de detalhe da receita: título, foto, lista de ingredientes exatamente como no texto fornecido (não reescrever, não resumir, não inventar), modo de preparo passo a passo numerado exatamente como no texto fornecido, e quando existir, rendimento e validade.
5. Tela "Meus Ebooks": 5 cards de download (vou te mandar os PDFs reais depois — por enquanto use estes 5 nomes de arquivo em /ebooks/ como placeholder de link, e gere uma capa ilustrada elegante estilo confeitaria pra cada um):
   - /ebooks/recheios-lucrativos-1.pdf — "Recheios Lucrativos que Não Vão ao Fogo"
   - /ebooks/recheios-rentaveis.pdf — "Recheios Rentáveis Que Não Precisam de Cozimento"
   - /ebooks/brigadeiro-sem-fogo.pdf — "Brigadeiro Sem Fogo"
   - /ebooks/receitas-brigadeiros.pdf — "Receitas de Brigadeiros"
   - /ebooks/recheios-moca.pdf — "Recheios Lucrativos (linha Moça)"
6. Tela Perfil simples (como nos outros apps): estatísticas (nº de receitas, categorias) e botão "Instalar app".

PWA / INSTALAÇÃO NA TELA DE INÍCIO (IMPORTANTE, o usuário pediu explicitamente): implemente manifest.json, service worker básico, e um botão "Instalar Receita Sem Fogo" que dispara o prompt nativo via evento beforeinstallprompt no Android/Chrome, e no iPhone (Safari) detecta o user agent e mostra um tutorial manual explicando "toque em Compartilhar > Adicionar à Tela de Início". Isso tem que funcionar igual já implementamos no app Appflix — o objetivo é a pessoa conseguir baixar/instalar o app na tela inicial do celular dela.
